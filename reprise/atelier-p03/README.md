# Atelier de reprise — état attendu en fin de matinée

Page structurée, formulaire accessible, liste vide, CSS responsive. À utiliser seulement si votre atelier du matin ne s'affiche pas correctement : voir la section « Si votre atelier du matin est cassé » dans `APRES-MIDI-J1.md`.

Depuis ce dossier, une fois copié à la place de `atelier` : `npm start`, puis `http://127.0.0.1:3000`.
